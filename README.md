# Passion-projects

## transcript

Local, offline video/audio → transcript → structured summary. Point it at a meeting, lecture,
interview, or any recording with no captions, and get back timestamped text, subtitles, and a
speaker-labelled document — entirely on your own machine. Works on Apple Silicon (fast, measured
path), and on Windows, Intel Mac, or Linux (CPU-based, newer path).

→ [`transcript/`](transcript/) — the transcription tool, full install walkthrough, time-benefit
numbers, and security notes.

→ [`transcript-to-summary/`](transcript-to-summary/) — the downstream step that turns a raw
transcript into key points, decisions, action items, and a chapter outline.
